## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件写得好不好，也不评它是否应该成为事件的代表稿。同一事件的官方稿、媒体稿、转载会在模型外归组并选代表。
- 输入故意不提供信源等级、信源名称、旧模型分数或精选门槛。不要猜这些信息，也不要把国家队、头部公司、长正文、术语、数字很多当成自动加分项。
- 可以用稳定的行业知识理解一个对象在产业链中的位置；事件是否发生、处于什么阶段（计划、签约、试验、首飞、入轨、取证、交付、量产）、具体数字，只能以输入材料为准。
- 标题与正文冲突时以正文为准。正文很短不自动低分，只要主体、动作、阶段和核心事实清楚，仍可正常判断。

## 二、五轴，各 0–10 整数

1. `sig` 实质份量：它在两个行业的时间线上是节点（首次入轨、可回收成功、型号合格证、大额融资、重大政策、关键订单交付），是这周值得知道的变化，还是当天的脚注。
2. `nov` 信息增量：材料带来了多少明确的新认知——新事实、新数据、新型号参数、新方法、技术原理的清楚说明，而不是标题看起来有多新。旧闻重提、例行通稿为低。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持：主体、时间、数字、证书名称、任务批次、轮次与投资方是否具体。官方公告足以证明“宣布、签约、发射”这一动作，但不能自动证明宣传中的性能与前景。传闻、“据悉”、无来源的估值为低。
4. `reson` 共振面：多少{{siteName}}读者会觉得与自己有关——涉及赛道头部或活跃的一级市场公司、影响技术路线或估值锚、影响整个行业的政策与空域、形成行业热议。

## 品味规则

### 必须正常评价的价值

- 商业火箭的首飞、入轨、回收与复用，关键发动机试车；eVTOL 与飞行汽车的首飞、转换飞行、型号合格证 / 生产许可证 / 运营合格证等适航节点；卫星批量组网、手机直连卫星等能力节点。
- 一级市场公司的融资：轮次、金额、投资方、估值、上市辅导与 IPO 进展，只要主体和轮次清楚，都是读者要知道的；金额越大、投资方越有代表性、越能提供估值锚，sig 与 act 越高。
- 有订单金额、交付数量、产能、营收或航线运营数据的商业化进展。
- 讲清楚一项关键技术的原理、路线差异、成本结构或技术难点的解读（例如液氧甲烷与液氧煤油、复合翼与倾转旋翼、相控阵与激光星间链路），即使不是当天新闻，只要具体、准确、对从业者和投资人有用，就按 nov 与 act 正常给分。
- 空域开放、低空飞行服务保障、适航审定、频轨资源、发射许可、地方低空专项政策等会改变行业规则或节奏的政策。
- 海外同行的关键节点（SpaceX、Blue Origin、Rocket Lab、Joby、Archer 等），只要它会改变国内读者对技术边界、商业模式或估值的判断。

### 必须压住的噪声

- 股评、涨停与异动、概念股梳理、研报荐股、主力资金，`sig ≤ 2` 且 `act ≤ 2`。
- 只有“拟”“计划”“有望”“将于”“正在洽谈”，没有签约、试验或参数等实质内容，`nov ≤ 3` 且 `cred ≤ 4`。
- 企业宣传、展会亮相、领导调研参观、合作意向框架协议（无金额、无产品、无时间表），`sig ≤ 3`。
- 地方政府泛泛表态、会议综述、口号式规划（无具体措施、资金、空域或项目），`sig ≤ 3`。
- 新闻摘要合集、早报、周报等多事件打包且没有单一焦点，`sig ≤ 3`。
- 融资只有“完成新一轮融资”而没有主体、轮次或投资方中的任何两项，`cred ≤ 4`。
- 宏大观点、行业“万亿赛道”展望，没有新数据、新因果或可复用框架，`sig ≤ 3` 且 `nov ≤ 3`。

## 事件、转述与材料不足

- 不因为材料是转述、转载或二手报道就自动扣事件分；后续归组会把它合并到更好的一手代表稿。但不能把被引用者没说过的效果、因果或阶段补进事件，材料只能证明较弱主张时，`cred` 和相关轴随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认主体、动作和阶段，各轴都不高于 3。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强的故事。
