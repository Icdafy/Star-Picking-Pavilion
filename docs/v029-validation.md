# v0.2.9 验证记录

## 标题栏与滚动区域

标题栏背景使用完整窗口宽度，内容区 `#appViewport` 从原生标题栏高度处开始。根窗口不产生滚动条；内容区的原生轨道在标题栏下方留出 4px，胶囊滑块、配色、悬停与拖拽反馈沿用。背景、标题栏与原生窗口按钮仍位于窗口坐标系；内容区内的侧栏、工具栏及日期分组头按内容坐标吸顶。

回到顶部、导航切换、滚动态和实时轮询的阅读位置改为读取内容区。内部列表仍保留自己的滚动范围；减少动画时关闭内容区平滑滚动。新用户默认状态及老用户偏好继续沿用 v0.2.8。

真实 Electron 滚动条专项已验证双主题、12 组背景预设、窗口右侧边界、轨道起点、原生拖拽、滚轮、Ctrl+End／Ctrl+Home、内部列表与系统强制颜色。旧布局矩阵仍检查 4 种窗口、4 档缩放、7 个视图，共 112 种组合。

测试根据滚动容器变更改读内容视口的位置和尺寸，保留原有几何、滚动、阅读位置和安全断言；桌面安全测试的临时恶意链接放入实际内容视口，确保它是可点击的页面内容。

## 信源实测与清理

2026-10-05 在全新隔离目录逐条真实采集，没有调用模型或读取用户数据库。首轮 190 个启用信源为 80 有内容、1 空结果、109 失败；东财搜索出现 HTTP 200 空正文。核对[东财官网搜索脚本](https://so.eastmoney.com/newstatic/js/page/search_main.js)，对齐高亮字段、来源头及严格响应数组校验。30 条分页和已有关键词守卫保留。

同一东财主机采用串行请求并在请求结束后间隔 350ms；HTTP 200 空正文等待 1 秒后仅重试一次，持续空正文或异常结构仍报错。仅串行的中间轮次出现 75 个空响应，保留原始失败记录，不以有成功轮次就宣称可靠。加入限速及有界重试后，最终严格审计 **186／186 返回内容，空结果 0，失败 0**。公开信源可能随后改变；该结果对应本次实测时刻。

默认目录从 221 项清理到 186 项，删除 35 个监控入口：

- 原有 31 个默认停用项，包括依赖自建 RSSHub、受限公众号、不可达聚合 RSS、空页面及停用 API 占位。
- 东财检索·沃飞长空、东财检索·傲势科技、东财检索·腾盾科技：本轮多页、双排序串行复查仍为空。
- 钛媒体 RSS：多轮返回 HTTP 502 或超时。

种子版本从 11 升到 12，新目录没有 `enabled:false` 条目。已有库升级时，已知失效项先停用，然后一次性移除所有停用入口。使用 `removed_at` 将入口从信源页隐藏并停止采集，保留来源行和外键，因此历史文章、星标、事件、融资引用、采集统计及归档仍能读到来源。后续手工停用不触发重复批量移除；启用和停用项都可明确移出监控。PATCH、重试及导入拒绝已移除入口，明确提报同地址可恢复原来源编号。

实时审计的原始 JSON、请求调查和失败轮次位于被忽略的 `work/v029/`，其中最终通过记录为 `sources-final-paced.json`；不打包用户数据或本机测试库。
