- 原有 31 个默认停用项，包括依赖自建 RSSHub、受限公众号、不可达聚合 RSS、空页面及停用 API 占位。

种子版本从 11 升到 12，新目录没有 `enabled:false` 条目。已有库升级时，已知失效项先停用，然后一次性移除所有停用入口。使用 `removed_at` 将入口从信源页隐藏并停止采集，保留来源行和外键，因此历史文章、星标、事件、融资引用、采集统计及归档仍能读到来源。后续手工停用不触发重复批量移除；启用和停用项都可明确移出监控。PATCH、重试及导入拒绝已移除入口，明确提报同地址可恢复原来源编号。
