# 摘星阁 Dashboard 功能覆盖与 UI/UX 复查

## 结论

浅色版的视觉基线可以保留，但首页应从“管理驾驶舱”收敛为“研究工作台”。全部真实功能必须有稳定入口和正确状态语义，不等于把全部管理、设置与异常详情同时堆进首屏。

产品的合理边界是：

- 首页负责态势、内容、可信度、异常和高频动作。
- 二级页负责完整研究、管理、配置、审计与维护。
- 加载、空、降级、失败、忙碌和部分成功使用统一状态系统呈现。

## 信息架构

### 一级导航

1. **总览**：今日漏斗、重点情报、热点、异常信源、归档连续性。
2. **情报**：精选 / 热点 / 全部动态 / 星标四个页内标签，领域与七分类筛选、搜索、复制与导出。
3. **日报与归档**：日报历史、分类章节、重新生成、复制、Markdown 导出；研究归档的目录、启停、立即保存、补存和完整性状态。
4. **信源**：信源列表、健康、失败次数、退避时间、解除退避、新增、编辑、启停与软移出。
5. **工作台**：核心词库、常用网址、情报备忘。
6. **设置**：AI 与凭据、采集调度、存储治理、桌面运行、显示与快捷键、关于与更新。

### 设置二级页

- **AI 与凭据**：API Key、接口地址、模型、保存、测试连接、清除凭据；明确 Windows 加密与启发式降级。
- **采集调度**：采集间隔、RSSHub 地址；区分“定时采集”和“界面自动刷新”。
- **存储治理**：库内情报、到期数量、数据库/WAL/SHM、可回收空页、桌面缓存、迁移残留、旧版数据、保留周期、清理、压缩与安全删除。
- **桌面运行**：关闭到托盘、登录启动及其回读/失败状态。
- **显示与快捷键**：浅色/深色、四档缩放、完整快捷键帮助。
- **关于与更新**：当前版本；仅在发现、下载、待安装或失败时显示更新状态，不虚构“已是最新版”。

## 首页必须直接呈现

- 全局搜索；搜索范围写为“标题、摘要与实体”。
- 核心词库快捷入口和 207 词提示。
- 持续监测开关、立即采集分析。
- 今日捕获 → 相关情报 → 今日精选，以及待分析、启用/总信源、星标数。
- 精选 / 热点 / 全部动态 / 星标标签。
- 低空经济 / 商业航天领域筛选和七分类入口；领域筛选必须放在情报模块内，避免暗示会影响全局 KPI。
- 3–5 条可扫读情报：来源名、T1/T1.5/T2、时间、分类、质量、热度、突破、多源数、摘要、研判、复制与星标。
- 每条情报标记“AI 研判 / 本地规则 / 待分析 / 分析异常”。
- 当前热点；热度用琥珀色，不与错误红色混用。
- 异常优先的信源列表，而非只画健康环图。
- 研究归档：最近成功、下一次、待补存和“后台保障是否开启”。
- 非打断式“发现 N 条新情报”入口。

## 二级页承载的功能

- 五维评分完整条形图、突破证据、主题、实体、原子事件。
- 事件簇全部报道和多源核验。
- 日报日期浏览、章节正文、重新生成和导出。
- 归档目录、失败记录、补存、校验与冲突处理。
- 完整信源管理和采集累计数据。
- 15 组、207 词的词库浏览、别名、权重和库内命中数。
- 常用网址分类、置顶与键盘焦点恢复。
- 情报备忘最近 50 条、记录和删除。
- API、RSSHub、保留周期、缓存、旧库、托盘、自启、主题、缩放、快捷键与更新。

## 必须修正的产品语义

- “检索核心词、实体与事件”改为“检索标题、摘要与实体”；当前没有直接搜索事件 JSON 的能力。
- “实时捕捉/实时采集”改为“持续监测/定时采集”；系统不是 WebSocket 实时流。
- “导出 .md”改为“导出 ▾”，菜单承接 Markdown 与纯文本。
- “删除信源”统一为“停用”或“移出监控”，历史文章保留。
- 单信源动作写“解除退避”，不承诺立即抓取；全量立即动作仍是“立即采集分析”。
- “仅存本机”改为“核心数据本地保存 · 凭据由 Windows 加密”；配置 AI 后会向用户指定的模型服务发送选定文本。
- 不使用无明确定义的“存储健康”；用“受管占用”“待处理 N 项”或“已完成统计”。
- 八段式管线只作为处理方法说明，不使用逐段实时完成勾或百分比。

## 交互与视觉规范

- 信息流优先，系统状态退居次要；减少重复状态带、环图和装饰性流程条。
- 质量分使用玉绿，低空经济使用青绿，商业航天使用靛蓝，热度/突破使用琥珀，红色仅用于失败和阻断。
- 默认情报卡只显示摘要态；五维、实体、突破证据和原子事件渐进展开。
- 主体文本建议不低于 14 px，辅助文字不低于 12–13 px；关键文本对比度目标至少 4.5:1。
- 点击热区至少约 40×40 px；状态不能只依赖颜色，必须配合图标和文字。
- 800×600 时：侧栏折叠为图标栏，KPI 换行，右栏落到主流下方，状态摘要仅保留异常与下一次归档；不做横向滚动。
- 1440 px 以上维持双栏研究工作台，情报列表内部滚动或继续加载。

## 状态系统

### 加载

情报流、日报、信源和词库使用稳定骨架，避免布局跳动。

### 空状态

- 无情报：立即采集或等待定时采集。
- 搜索无结果：更换关键词或清除筛选。
- 星标为空：说明星标会永久豁免清理。
- 日报/精选为空：明确可能尚未采集或全部低于质量门槛。

### 降级

- 未配置 API Key：显示“启发式模式”，不是错误。
- 外部网络不可用：本地情报、星标、日报和已存档内容仍可读。

### 错误与部分结果

- 后端中断、归档目录不可写、连续失败信源、更新失败使用持久提示和明确恢复动作。
- 存储统计未知显示“暂不可用”或“≥ 已知值”，不能显示 0。
- 缓存部分释放与待重启清理分别呈现。
- 托盘不可用时明确说明窗口将保持显示。

### 忙碌

立即采集、加载更多、日报重生成、归档保存、清理和压缩拥有相互独立的忙碌/禁用状态。
