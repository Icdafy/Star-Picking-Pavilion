# v0.2.31 跟手风格验证

保留范围柔光，新增流星拖尾、星尘粒子和弹性光环。设置可选择各风格独立尺寸、任意六位颜色、八组配色预设与 10—100% 强度。旧偏好缺少新增字段时仍恢复原有柔光、开关、尺寸与颜色，不改写用户偏好文件。

## 参考与打磨

- [Cuberto Mouse Follower](https://github.com/Cuberto/mouse-follower)及其[源码](https://github.com/Cuberto/mouse-follower/blob/dev/src/index.js)：参考速度形变及避免旧目标动画累积的设计；本版用解析弹簧按真实时间推进，没有引入 GSAP 或复制该库代码。
- [Codrops Motion Trail](https://tympanus.net/Development/MotionTrailAnimations/)与[Animated Mesh Lines](https://tympanus.net/Development/AnimatedMeshLines/)：参考短寿命尾迹、渐细与光感；本版采用适合阅读界面的 Canvas 光带，没有采用网站图像或 WebGL 素材。
- [Tholman Cursor Effects 星尘源码](https://github.com/tholman/cursor-effects/blob/master/src/fairyDustCursor.js)：参考预渲染粒子和移动时发射的思路，本版使用几何光点、固定粒子池与真实时间漂移／寿命，没有复制字形素材或按帧倒计时算法。
- [MDN Canvas 优化指南](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)：复用预渲染光点、避免逐段 shadowBlur、按帧合并、仅清除脏区域。逻辑轨迹最多 96 点，星尘最多 96 个、lite 档 36 个；缓冲区上限约 400 万像素，DPR 上限 1.5，lite 档 1。

流星由连续样条与一次填充的渐细光带组成，消除逐段描边的接头亮点。星尘按实际移动距离生成，静止不持续发射。光环仅修改 transform/opacity，停稳后停止 RAF。只由 pointermove 采样轨迹，布局或弹层变化产生的 pointerover 不重新唤醒绘制。透明手动 popover 保证装饰可出现在原生弹层上，pointer-events:none 保留命中，Esc 捕获阶段先撤销装饰。
