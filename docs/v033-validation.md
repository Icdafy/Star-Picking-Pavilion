# v0.3.3 验证记录

本版修复 v0.3.2 引入的一处重要排版缺陷：藏言录目录栏为“自动隐藏”时，打开右侧详情后把鼠标移到左边缘，滑出的目录会压住底部工具坞的左半截；在“固定”模式下排版正常。修复后以第一次使用者的视角把藏言录（新手引导 → 目录滑出 → 选条目 → 填变量 → 卡片墙 → 命令面板 → 新建 → 管理五个分页 → 主题 → 固定 / 自动 → 小窗口 → 窄屏）和摘星阁指挥栏重新走查一遍，顺带处理走查中发现的名牌遮挡、编辑器窄栏与指挥栏折列问题。

## 定位

- **根因**：`layout()` 在自动隐藏模式下把左侧占位记为 0（小岛舞台铺满左侧，这是 v0.3.2 的设计），工具坞随之以“视口 − 详情”的中心为轴。目录浮出时以 `z-index:2` 盖在上面，却没有任何代码让工具坞避让。固定模式下左侧占位等于目录宽 + 2 个栏间距，所以一切正常。
- **复现**（真实摘星阁窗口，详情打开，鼠标移到左缘）：1440 × 920 默认窗口目录与工具坞重叠 119 × 56 px，1180 × 780 重叠 228 × 56 px，1920 × 1080 重叠 34 × 56 px；被盖住的是“全景”“左转”（小窗口还有“右转”）。新手引导第 3–5 步按住目录时同样重叠。

## 实现

- **只改原始单文件、整份替换随包副本**：修改藏言录原始单文件后复制为 `electron/cangyanlu/藏言录.html`，两者仍逐字节一致（1,148,421 字节，SHA-256 `70e5af85d260c29b0c69663641253ef107a13d31201ca385b2b674e6519ec40f`，只含 LF），`test/cangyanlu.test.js` 同步校验和与字节数。
- **工具坞让位**：`layout()` 拆出 `placeHud()`。工具坞与提示条平时落在小岛中轴；目录浮出且工具坞左缘落在“目录右缘 + 一个栏间距”以内时，改按固定目录时的中轴（目录与详情之间）放置，目录收回后复原；没有冲突（如未开详情的宽窗口）时原地不动。小岛的取景不受影响，不会因目录进出而跳镜头。`Lib.set()` 每次切换都重排，并临时挂 `body.lib-swing`（600 ms），让工具坞借用目录的过渡：滑出 0.56 s `cubic-bezier(.16,1,.3,1)`、收回 0.4 s `--ease-io`，看起来像目录把它轻轻推开（参照 iPadOS 侧栏推开工具条）；详情开合仍用工具坞自己的 0.9 s 曲线。
- **窄窗口收缩**：放不下时依次收起文字（`compact`）、四个镜头按钮（`compact2`）、名牌开关（新增 `compact3`，<kbd>L</kbd> 键照常可用）。1180 × 780 窗口目录浮出时由此留出 28 px 间距，而不是贴着两侧面板只剩 5 px。
- **新手引导**：从讲目录的步骤（2–5）进入第 6 步时目录立即收回，等 450 ms 工具坞回到中轴再定位聚光圈，聚光圈准确套住“主题”按钮。
- **名牌避让**：`placeHud()` 把顶栏三卡、工具坞与看得见的目录 / 详情面板的最终落点交给 `Scene.setHud()`。名牌之间先按原规则避让，再避开这些卡片：钻到顶栏卡片底下的往下让（引线最短 6 px），让不开就淡出；压在工具坞上的往上抬；被两侧面板压住一角的直接淡出（同地图标注的碰撞剔除：宁可不显示，也不露半截）。已淡出的名牌要多让出 4 px 才浮现，镜头慢移时不闪。
- **编辑与阅读细节**：编辑器“标签 | 适用模型”两列改为 `minmax(0,1fr)` 等分、标签输入框 `width:0`（原先标签输入框的默认宽度把下拉框挤成一个字宽，“适用模型”标签也折成两行）；详情栏容器宽 ≤ 380px 时保存提示只显示“已自动保存”（原先截成“已自动保存 · 可在…”）；正文里显示内容 ≤ 8 字的变量整块换行（原先“简洁、专 / 业”“原 / 文”断成两截）；命令面板搜索结果去掉正文开头的列表符号（原先出现“新手教程 · · …”）。
- **摘星阁指挥栏**：宽屏指挥栏 `.nav` 显式 `flex-wrap: nowrap`。原规则沿用窄屏顶栏的 `flex-wrap: wrap`，v0.3.0 加入第十一个视图后，窗口内容区低于约 820 px 时标签列整体折到“工作区”右侧、溢出侧栏。另新增 52rem / 45rem 两档矮窗口压缩，并把 42rem 档的标签选择器提高到 `.app-stage .command-rail .nav-tabs .tab`：golden.css 后加载的 `:root:not([data-fluid="off"]) .tab { min-height: var(--ctl-h) }` 曾让矮屏压缩全部失效。

## 验证

- **复现脚本**（work/v033/probe.cjs，真实摘星阁窗口，临时数据目录、只复制界面偏好）：在 1440 × 920、1180 × 780、1920 × 1080 三档窗口里跳过引导、打开详情、用 `sendInputEvent` 把鼠标移到左缘，求所有 HUD 卡片两两交集。修复前三档都报告 `#lib∩#dock`，修复后三档在首页 / 详情 / 浮出 / 收回四个状态下均无交集。800 × 600 最小窗口为窄屏抽屉布局（详情是盖住工具坞的底部抽屉，属设计行为）。
- **新用户走查**（work/v033/journey.cjs，30 个步骤逐步截图并审计：卡片两两不相交、可见名牌不压任何卡片、guest 无控制台错误）：新手引导 6 步、引导后首页、左缘滑出、在浮出的目录里点条目、移开收回、填写变量、全部卡片墙、命令面板与搜索、新建提示词并输入正文、保存与完成、管理（外观 / 分类 / 数据与备份 / 回收站 / 快捷键）、主题切换、B 键固定与恢复、回全景、1180 × 780 小窗口浮出与收回、1000 × 720 窗口。结果：无重叠、无控制台错误。
- **指挥栏**（work/v033/railfit.cjs）：1300 宽 × 640 / 672 / 680 / 700 / 740 / 780 / 820 / 860 与 1440 × 920，默认字号下标签列溢出全部为 0；大字号下在栏内滚动，不再折列。

## 边界

- 让位只针对工具坞与提示条；镜头提示和键位提示只在拖动或按键漫游小岛时出现，那时目录不会浮出。
- 名牌淡出按卡片的最终位置计算；详情开合的 0.9 s 过渡期间，统计卡移动中可能与名牌短暂交错。
- 大字号（lg / xl）下矮窗口的指挥栏仍需在栏内滚动；窄于 70rem 时指挥栏回到顶部横排导航，不受本版影响。
- 安装包沿用未签名策略；安装、启动、单实例、退出、卸载与用户数据保留在一次性 Windows CI 执行，本机不运行安装器。
