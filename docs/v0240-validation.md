# v0.2.40 验证记录 · 更新弹窗图标修复与自动清理开关

## 范围与原因

- 应用内动态及静态 SVG 于 v0.2.27 更新；Windows 图标生成脚本仍以 v0.2.26 的 `renderer/logo.png` 为源。`build/icon.ico` 因而过期，安装器、卸载器、窗口与托盘全部引用了旧资源。现统一从 `renderer/logo-still.svg` 生成 PNG 和多尺寸 ICO，并将一致性校验纳入构建。
- electron-updater 6.8.9 的 `checkForUpdatesAndNotify()` 只保留通知 title/body，未指定 icon；改为显式原生通知，传入当前图标并设置与安装快捷方式一致的 AppUserModelID（读取保留在包内的 `config/brand.json`）。启动、定时与手动检查共用协调器，下载就绪后统一通知，点击只打开应用。通知不可用时不影响更新状态。
- 新增 `collect.automaticCleanup`，旧设置缺省为 `true`，延续已有行为；关闭后不再定时删除过期情报，手动清理仍可运行。每日 08:25 的定时清理继续依赖自动采集，界面明确区分清理关闭、已开启但自动采集关闭、两项已开启三种状态。

- 当前安装包继续采用未签名策略；Windows SmartScreen 可能提示未知发布者，README 与发布说明保留校验指引。
