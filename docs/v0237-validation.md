# v0.2.37 设置页重新设计与使用逻辑修复：实现与发布验证

2026-10-17（北京时间）。基线为 v0.2.36 收尾提交 `05b098f`。范围是设置页除“新闻推送”外的全部章节；新闻推送只做了通用类名提升（外观与行为不变）。审阅截图使用复制到临时目录的用户数据库与设置（不含密钥），走查使用全新的隔离配置目录，均不修改用户正式数据。

## 以新用户身份走查发现的问题

**版式与信息量**

1. 十个章节各用一套排版：有的有英文小标题和徽标，有的只有一行标题；有的是卡片网格，有的是表单加整段说明。每节末尾一到三段 `hint` 文字（“精选链：预筛 → 同一标准独立评分两次……”“调的是整套版面的比例尺……”），配置文件路径、`npm run eval:selection`、提示词哈希（`content-understanding@2ccbfc7234e3`）等维护者信息直接铺在页面上。
2. 目录是 01—10 的平铺编号，常用与不常用混在一起；“情报备忘”藏在“采集调度”底部；“跟手动效”放在“显示与排版”里，与“界面氛围”分开。
3. 外观预览卡占约 180 px 却不反映任何真实设置；存储治理用 1 张大卡 + 2 张小卡 + 5 张明细卡 + 3 张操作卡，同样的信息需要两屏。

**使用逻辑**

4. **开关不即时生效**：“自动采集分析”是开关，却要再点下方“保存”；拨动后离开页面，开关显示开启而服务器仍是关闭。
5. **保留天数静默回落**：清空“情报保留天数”后保存，会被 `Number('') || 180` 悄悄改成 180 天；“立即清理”使用的是已保存的天数而不是输入框里的值，两者可能不一致。
6. **“恢复默认”误伤**：“界面氛围”的“恢复默认”把全部外观偏好复位——动态背景被关掉（默认值为关），“跟手动效”的开关、样式、尺寸与颜色也一并被重置。
7. **从属选项不随开关收起**：动态背景或跟手动效关闭后，色相、壁纸、尺寸等选项仍可拖动，但没有任何可见效果。
8. **依赖关系没写**：每日 08:25 的过期清理与日报 / 周报 / 月报只在“自动采集”开启时运行，存储一节只写“自动清理未开启”，看不出要去哪里开。
9. **按钮含义不清**：每日资料库的“选择或更改位置”实际会同时开启自动归档；未选位置时“立即保存最近一期”是灰的但没有原因。
10. **模型一节**：缺少密钥时只提示“请在下方编辑它并填入密钥”，需要自己找“编辑”；“测试连接”在没有密钥时仍可点；提供商上的“分析中”看起来像有任务在跑。
11. 深浅主题只能在顶栏切换，设置页里找不到。

## 设计与实现

- **统一版式**（`renderer/index.html`、`renderer/styles.css`）：每节为 `.set-head`（kicker + 标题 + 一句话说明 + 徽标）→ 可选 `.set-hero` 状态区 → `.set-panel` 行面板（`标签 | 控件`，说明压缩为一行 `small`）。v0.2.36 推送面板的 `.push-panel / .push-opt / .push-hero / .push-step` 提升为通用的 `.set-*`，推送专属规则保留。目录按“情报处理 / 送达与归档 / 外观 / 系统”分组、去掉编号，“情报备忘”独立成第 11 节，“跟手动效”并入“氛围与动效”。说明文字精简，维护者信息放进“工作原理与费用”“评分细则”折叠区。
- **改动即保存**（`renderer/settings-form-controller.js`、`renderer/settings-view-controller.js`）：`saveCollect(fields)` / `saveRetention(fields)` 只提交被改动的字段，新增 `discard(fields)`；自动采集开关、间隔胶囊（15 分钟—12 小时）与自定义回车、RSSHub 回车 / 失焦、保留期限胶囊与自定义均即时保存并 toast 回执；保存被拒时说明原因并读回服务器值。去掉 `#btnSaveCollect` / `#btnSaveRetention`。保留天数空值、小数、越界直接拒绝。
- **恢复默认外观**（`renderer/aqua-shell.js`）：只复位 `aqua*` 参数，不含 `aquaEnabled` 与跟手动效；开关改为按钮式开关（`aria-pressed`），不再覆写按钮内部结构。
- **从属选项收起**：`.aqua-only` / `.pointer-only` 行在对应开关关闭时由根属性选择器隐藏。
- **写明依赖与按钮含义**：存储“自动清理”行按调度状态说明（`renderer/storage-maintenance-controller.js`）；自动采集列出随之运行的任务；每日资料库按钮按状态显示“选择文件夹并开启 / 更改文件夹并开启 / 更改文件夹”，未选位置时保存按钮带说明（`renderer/daily-archive-controller.js`）。
- **模型**：章节徽标“已就绪 / 缺少密钥”；警告附“填入密钥”（展开编辑卡并聚焦密钥框）；无密钥时禁用测试；“分析中”改为“当前使用”。
- **显示**：新增深浅主题胶囊，经 `MutationObserver` 与顶栏按钮、Alt+T 同步。
- **精选标准**（`renderer/intel-views.js`）：门槛与用量改为两行，权重表、配置路径与提示词版本折叠为“评分细则”。
- **预算**：外观预览卡、存储卡片网格、维护卡片网格与归档专用布局退役，页面 CSS（CI 口径）由约 301,105 B 降到约 293,800 B，净减约 7 KiB；脚本 27、关键帧 20、预算上限 296 KiB 不变。

## 限制

- 自动采集状态区的副标题沿用调度状态文本；在关闭调度器的测试环境（`STAR_PICKING_PAVILION_NO_SCHEDULER=1`）中开关开启时仍显示“在线待命”，正式运行时显示下一次自动采集时间。
