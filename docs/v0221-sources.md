## 外网检测与静默跳过

检测和海外 RSS／HTML 使用同一 HTTP(S) 代理路径：优先环境 HTTP_PROXY／HTTPS_PROXY，否则读取 Windows 启用的手动系统代理，最后直接连接。遵守 NO_PROXY，本机地址绕过代理，不记录代理凭据。支持手动 HTTP(S) 代理，不解析 PAC 或独立 SOCKS 配置，不替用户配置 VPN。

Cloudflare trace 查询出口 IP／国家，Google 与 Cloudflare 的 generate_204 探针并行检测，单请求 3.5 秒截止、不跟随重定向、仅 HTTP 204 视为探针成功。Google 成功可直接启用；否则要求已知非 CN 出口且 Cloudflare 探针成功。CN 出口实际能访问 Google 同样启用；IP 查询失败或未知不抛出错误，不将登录／拦截的 HTTP 200 当作成功。

IP 只保留脱敏形式（如 47.129.*.*），不写原始 IP 到数据库、日志或接口。可用缓存 5 分钟、不可用 2 分钟，同一在途检测共享请求；手动检测及立即全量采集强制刷新。无启用海外源时不发检测请求。

不可达时，16 个海外源在调度前排除，连“强制采集”也不调用它们；不更改 last_fetch_at、fetch_count、item_count、error_count、consecutive_errors 或退避状态。返回“等待外网”的独立跳过原因，国内信源继续，页面采用中性状态并可筛选。恢复网络后自动复查采集。网站自身 403／格式变化与整体外网不可达不同，实际已尝试的站点错误沿用原有退避。

## 中文翻译与既有数据

海外外文标题／摘要先进入待译队列，通过现有分析模型译为简体中文，保留公司、机构、人名、品牌、型号和任务名等英文专有名词。混排中未翻译的普通英文也进入队列；已有中文及英文专名混排不重复翻译。外部导入标为海外的内容使用同一队列。

使用现有模型配置、超时、回执和小时／日预算，8 条一批、每轮最多 40 条；响应需条数、ID、中文和原文名称一致。坏译文不写入有效回执，失败延迟两分钟后按单条重试，预算暂停不累计重试失败。标题／摘要／FTS 在同一事务入库，中文随后进入原有双行业相关性筛选、评分、公司融资识别和出刊。模型理解若退回英语或丢失已保留名称，使用已验证译文兜底。

原始标题、摘要、URL、发布时间保留；新增可空翻译状态／JSON／重试时间字段和队列索引，不改写星标、用户设置或旧归档。旧海外材料缺中文时补入队列，成功后更新原有外文展示字段及对应事件标题／摘要。未配置密钥、预算耗尽或暂时失败时，原文保留等待翻译，普通信息流不展示未译外语；已有星标显示中文待译提示，信源页显示待译数量。翻译范围为新闻标题和可获取摘要，不承诺翻译付费墙或整篇外链正文。

种子库升级只对明确的 6 个入口移出监控，地址和选择器修复保留启停状态与原 ID；不会再次清除本版用户主动停用的自定义信源，已移出条目不因地址迁移重新加入。翻译实测使用本地兼容模型 HTTP 测试服务，未调用用户付费密钥；真实模型的逐条语言质量仍取决于所配置模型，原文链接用于核验。
