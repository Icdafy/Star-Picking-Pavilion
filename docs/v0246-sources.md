# v0.2.46 信源梳理

审计日期：2026-10-24（Asia/Shanghai）。种子库升级到 v15，完整名单见 [sources.default.json](../config/sources.default.json)。产出统计取自本机用户库的只读副本（2026-08-10 至 10-24，7,821 条入库），只读取各信源的轮次与入库、相关、精选计数，不读取模型密钥，副本与探测脚本保存在被忽略的 work/v0246。

## 口径

每个信源按上线以来的“采集轮次 / 入库 / 相关 / 精选”核算。入库是该信源第一个收录的文章数，同一篇文章若已由别的入口先收录，不再计入；因此“返回很多结果但入库为 0”表示结果全部重复。删减按三条规则执行：

1. **零贡献检索线**：检索类入口上线后长期 0 相关，或结果始终已被主检索线先行收录。
2. **噪声流**：入库 10 条以上、相关不足 5%、精选为 0 的综合入口。
3. **结构失效**：页面或栏目已改版，上线以来 0 条入库。

两类入口不适用上述规则：官方一手源（国家部委、监管机构）即使近期没有相关新闻也保留；公司池中的公司监控线保留，没有新闻不等于失效，它的价值在于事件发生时第一时间捕获。
