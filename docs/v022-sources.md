# v0.2.2 一级市场信源实测

2026-09-30 用应用实际采集器（`server/collectors/*`，与定时采集同一代码路径、同一 User-Agent）逐个验证，全部为公开免费入口，无需登录或付费数据 API。首轮条数是采集层返回、入库前的数量；是否进入精选和一级市场仍由预筛、两次独立评分与融资抽取决定。覆盖持续扩展，不保证全网所有融资；未公开交易与需登录的数据库不在覆盖内。

## 交易所上市进程（新 API scheme）

| 信源 | 地址 | 首轮 | 说明 |
|---|---|---:|---|
| 上交所·科创板IPO·航空航天 | `sseipo://?csrc=C37&days=540` | 4 | 中科宇航、蓝箭航天、微纳星空（已问询），中电科蓝天（注册生效） |
| 上交所·科创板IPO·航天 | `sseipo://航天?days=540` | 1 | 按公司名称检索，补 C37 之外行业代码的航天企业 |
| 深交所·IPO审核·航空航天 | `szseipo://?industry=航空航天&pages=3&days=540` | 3 | 腾盾科创、成立航空、晋铭航空（已问询） |

数据来自 `query.sse.com.cn`（科创板发行上市审核项目列表）与 `listing.szse.cn`（项目动态）。每个“项目 × 审核状态”生成一条资料，状态变化（受理 → 问询 → 上市委 → 注册）即一条新的上市进程报道；标题只写交易所公开字段，不推断审核结果；超过 540 天未更新的历史项目不入库。按名称检索“卫星”的两条入口在 540 天窗口内为空，未加入默认信源。

## 未接入

- Crunchbase News、SpaceNews、Payload、DroneLife、NASASpaceflight：浏览器可打开，但对应用的采集请求返回 HTTP 403，不做规避，未接入。
- 36 氪融资频道与创业邦融资频道：列表以前端渲染为主，直连只得到空壳或全行业泛资讯，未接入。
- IT 桔子、烯牛、企名片、鲸准等：需登录或付费，不符合免费公开原则。

与 v0.2.1 相同：三个用户提供的文章链接实测均要求微信环境验证，入口保留并标为默认停用、访问受限，**不是采集成功的来源**。持续接入需在信源页添加该账号可用的公开订阅地址。
