# v0.3.1 验证记录

本版只改藏言录的版式与新用户流程：v0.3.0 把藏言录完整并入摘星阁后，默认窗口里它的左右两栏偏宽、小岛被挤窄、顶栏卡片高矮不一。本版按黄金分割为藏言录重新排版，摘星阁宿主的脚本、样式、预算、webview 接线与情报功能均未改动。

## 实现

- **只改原始单文件、整份替换随包副本**：修改藏言录原始单文件后复制为 `electron/cangyanlu/藏言录.html`，两者仍逐字节一致（1,130,155 字节，SHA-256 `9eda78ed0c8a95d58c1b6422fa7072205d6e72a587816a9c5411e2bb5fc152d1`，只含 LF），`test/cangyanlu.test.js` 同步校验和与字节数。
- **黄金分割栅格**（藏言录 `:root` 的布局令牌）：`--g` 外边距与栏间距，`--bar` 顶栏与工具坞同高，面板顶 `2g + bar`；目录栏 `clamp(256px, 19.1vw, 336px)`（19.1% 与摘星阁导航栏 `1 : φ³` 同一比例）；详情栏 = (视口 − 目录 − 4g) × φ⁻²，即详情 : 小岛舞台 = 1 : φ，`clamp(300px, …, 560px)`。布局脚本、场景取景（`Scene.setFit` 改为接收顶栏与工具坞占高）、建筑信息卡与新手引导聚光灯都读同一组令牌，不再写死 112 / 104 / 20 等像素。
- **对齐**：品牌、统计、时钟三卡同顶同高，品牌卡与目录栏同宽；时钟改为“时间 | 日期 / 节气”横排（手机宽度改回竖排），不再比另两张卡高出一截压住详情栏；工具坞改为与顶栏同高的整条玻璃工具栏（镜头一组、内容一组）；两侧面板底栏高 `bar − 1px`（面板自带 1px 描边），上缘与工具坞上缘、面板下缘与工具坞下缘对齐，按钮中线一致；弹窗黄金点落在视口 38.2%，与摘星阁对话框一致。
- **紧凑档**（宽 < 1480 或高 < 860，嵌在摘星阁默认窗口即属此档）：g 13、bar 56、内边距 12，字号取 φ 四分音阶（11.5 · 13 · 14.7 · 16.5 · 18.6 · 21），按钮 38–44px；详情栏宽 ≤ 380px 时由容器查询把“编辑”收成图标、“完成”去掉快捷键角标，主按钮“复制填好的提示词”完整显示。宽松档（全屏打开）保持原有尺度。
- **新用户流程修正**：建筑信息卡分类名不再折成两行；镜头操作提示与通知以舞台宽 `--stage` 为上限、自动换行，不再盖住两侧面板；“新建分类”的说明在窄栏里隐藏而不是折行；编辑器标题占位改短、语法提示不再把图标单独留在上一行；输入 `{{` 自动补全 `}}` 后再手动敲 `}` 会越过已有括号（与代码编辑器一致），不再多出一对；“适用模型”移入标签行，统计信息保持一行。
- **摘星阁措辞**：以 `cangyanlu:` 来源运行时（`EMBED`），保存提示、新手教程第 5 张、“数据与备份”的同步与存储说明、解除绑定提示与引导第 5 步改说“保存在摘星阁里”，不再提浏览器、无痕窗口或“这个 HTML”；独立打开文件时措辞不变。
