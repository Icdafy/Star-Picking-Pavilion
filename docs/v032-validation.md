# v0.3.2 验证记录

本版继续打磨藏言录，以第一次使用者的视角走查后集中处理三件事：左侧目录常驻占地方、字太细看着吃力、“藏言录”标题字体与摘星阁各模块不一致；同时把小岛中央的建筑改名为“藏言岛”。摘星阁宿主只新增一条字体路由，渲染脚本、样式、预算与情报功能均未改动。

## 实现

- **只改原始单文件、整份替换随包副本**：修改藏言录原始单文件后复制为 `electron/cangyanlu/藏言录.html`，两者仍逐字节一致（1,143,516 字节，SHA-256 `55177a1be973bb735739e923c3ed7df9a8aeb8403b201fa4faeb8d8a06cfe3d8`，只含 LF），`test/cangyanlu.test.js` 同步校验和与字节数。
- **目录栏自动隐藏**（藏言录设置 `libMode`，缺省 `auto`，可选 `pin`）：收起时目录位移出左缘、只留一枚 4 × 64px 的把手，`layout()` 把左侧占位记为 0，小岛舞台、统计卡与工具坞以整个视口为中轴。指针进入左缘感应带（`--g + 18px` 宽，自面板顶到底部外边距）驻留 70 ms 滑出，贴死最左 4px 立即滑出；从左侧进入窗口（如从摘星阁导航栏移入）视为路过，需驻留 450 ms；按着鼠标拖动小岛、弹窗 / 卡片墙 / 命令面板开着时不弹。离开 380 ms 后收回；输入框或键盘焦点在目录里、菜单或弹窗开着、拖动条目、新手引导讲到目录时不收；点到目录以外或按 Esc 立即收起。滑出 0.56 s 指数减速（无回弹）、收回 0.4 s 对称缓动，浮起时 `z-index:2` 压在工具坞之上并加深阴影。仅在宽 > 860 且指针可悬停时生效，窄屏仍为底部“目录”按钮唤出的抽屉。交互参照 macOS 程序坞与 Arc 浏览器侧栏。
- **固定入口**：搜索框旁新增图钉按钮（固定时填色、自动时斜置），<kbd>B</kbd> 键切换，“管理 → 外观 → 目录栏：自动隐藏 / 固定”同步；从固定改为自动时若指针在目录上先保持展开。快捷键表、新手引导第 2 步（讲到目录时自动展开并说明用法）、教程卡片 ①③④ 同步；引导结束后把手轻探两下提示目录位置。
- **字体统一**：藏言录 `--font` 以思源黑体（`Source Han Sans SC`，Google Fonts 发行名 `Noto Sans SC`）打头，标题 `--font-brand` 与正文同族。嵌在摘星阁时 `<head>` 里的小脚本插入 `fonts/source-han-sans-sc/index.css`，由 `electron/cangyanlu.js` 从 `renderer/fonts/source-han-sans-sc/` 原样提供：白名单正则只认 `index.css` 与 101 个 `noto-sans-sc-(数字|latin|latin-ext|cyrillic|vietnamese)-wght-normal.woff2` 分片，路径只由捕获段拼出，读过即缓存；CSP 的 `style-src` / `font-src` 加入 `'self'`。单独打开文件时插入 Google Fonts 的 `Noto Sans SC:wght@300..900`（脚本插入，不阻塞首屏，连不上换用系统黑体）；原来的标题书法字体子集不再请求。
- **加粗加深**：“藏言录”标题 823 字重（与摘星阁 `.view-title` 相同），紧凑档 23px、宽松档 27px；正文 450；条目名 600、分组名 750、按钮 600、详情标题 750，标签、元信息、菜单、通知、提示、统计说明等由 400 加到 500 左右。`--ink2` / `--ink3` / `--ink4` 由 #4a5366 / #8a92a3 / #b9bfca 加深为 #373f51 / #626a7d / #99a0ae：次要文字在白色上的对比度由 3.1 : 1 提高到 5.4 : 1（WCAG AA），二级文字由 7.7 : 1 提高到 10.5 : 1；变量输入框的“默认：…”占位改用 `--ink3`；正文、编辑器与提示框文字同步加深。
- **藏言岛**：中央建筑名牌、舞台无障碍名称与相关注释由“藏言阁”改为“藏言岛”。
- **新用户流程修正**：详情打开、舞台变窄时统计卡先在品牌卡与时钟之间平移（`--sx`），挤不下才隐藏，不再一开详情就消失；目录容器宽 ≤ 320px 时搜索框不挂 Ctrl K 角标，占位“搜索标题、标签、正文…”完整显示；命令面板预览去掉正文开头的项目符号（不再显示“新手教程 · · …”）；教程卡片 ③ 的“新建”同时指向底部工具坞的“＋”。

## 边界

- 自动隐藏只看指针位置，不读系统“自动隐藏任务栏”等设置；触屏或无悬停指针的设备按“固定”处理。
- 嵌在摘星阁时，左缘感应带位于藏言录视图内侧；鼠标越过视图左缘进入摘星阁外框时不会触发。
- 已有用户的新手教程卡片保存在各自数据里，不会被改写；需要新版教程文字可在“管理 → 数据与备份 → 恢复教程”放回缺失的卡片。
- 安装包沿用未签名策略；安装、启动、单实例、退出、卸载与用户数据保留在一次性 Windows CI 执行，本机不运行安装器。
