# v0.2.28 验证记录

日期：2026-10-07（北京时间）。本版修复未操作却持续显示分析中的问题，升级更新图标、Logo 大小与全局跟手动效。

## 原因与修复

旧版 `server/scheduler.js` 启动 2.5 秒后调用全量管线，另以 `setInterval` 独立轮询分析；即使没有本次采集，分析循环也可做归组、热度与付费编辑。前端将 `analyzeRunning`／`pipelineRunning` 显示为“分析中”，手动按钮还等待 `pending` 为零并在五分钟后自行停转，因而与真实任务有偏差。

本版删除启动任务、启动维护与独立分析轮询。`collect.automatic` 是明确的布尔开关，新用户与没有该字段的已有设置均默认为关闭；明确开启后才创建自动计时并启用定时出刊、快照与保留治理，每轮采集、分析与收尾全部完成后重新计时。关闭时取消后续自动任务，正在执行的一轮自然结束。历史配置中的分析间隔保留兼容，但不再生成分析轮询。

后端提供统一 `activity` 与递增 `revision`，通过同源、现有鉴权保护的 `/api/activity` 实时推送；统计查询使用同一状态，旧响应不能覆盖新推送。采集、分析、归组收尾统一显示“采集中”，完成或失败后恢复静态“在线”。按钮跟随该状态，不以剩余待判条数或五分钟计时决定忙闲；退出时关闭状态连接并移除订阅。

## 素材与交互

采用用户上传的 SVG（17,686 B），原稿 SHA-256 为 `4ffe6297f8a0a32dcced1143ea3840b4e3969f506759ecbc5de4fcf03c86030d`，`renderer/update-progress-loop.svg` 保留原始字节。同稿 GIF 为 5,384,573 B。SVG 更适合缩放、主题调色和进度控制。

更新按钮使用原稿圆环、圆盘与双箭头的原始路径；静态第一帧保留于 `update-progress-still.svg`，HTML 内嵌同一几何。原稿演示用的 6.4 秒模拟进度与旋转轨道不运行；真实进度来自既有更新 IPC，`pathLength=100` 映射百分比。非悬停保持图案，悬停／键盘焦点显示真实数字与外环，下载完成显示 100% 与重启入口，错误保留重试。按钮在工作区标识右侧余下区域中水平、垂直居中，颜色随深浅主题及外观色相适配。

Logo 从宽屏 2.55rem 放大至 3.5rem、窄屏 2.875rem 放大至 4rem，并向名称方向上移 0.5rem；原有 SVG 六条动画、悬停播放与静态回退保持。

跟手追光沿用已有委托事件与解析弹簧，覆盖全部十视图、导航、表单、披露、dialog 与 popover。每次最多两个表面与两个控件，鼠标静止收敛后无常驻 RAF；装饰层不拦截点击，不改变文字或命中范围。新增开关、80—800px 连续大小、精确数值、任意六位十六进制颜色及八组配色。共享偏好白名单、桌面持久化与浏览器恢复都包含新字段。系统减少动画、失焦、后台、低功耗与高对比度降级仍优先。

设计参考为 [Codrops Animated Custom Cursor](https://github.com/codrops/AnimatedCustomCursor/) 的延迟跟随思路；本版继续使用项目已有弹簧实现，无新增第三方代码或运行依赖。
