## 可复现问题与修复

1. **刊期草稿被当作定稿。** 周/月报只看当前时间已过截止，直接返回此前生成的草稿；日报也会复用截止前缓存。新用例先在截止前生成、补入最后一条资料、越过截止，旧实现遗漏资料。现在要求生成时间也达到截止，草稿在到期或缓存过期后重新生成，最终快照继续冻结；损坏的历史日报仍保留原行而只在内存恢复。
2. **旧导语与新内容错配。** 原实现只比较精选与融资数量，相同数量但标题/摘要变化时沿用旧模型导语。改为比较实际导语输入；未变化时保留导语。本版不额外调用付费模型。
3. **无效 ISO 周号。** 2021-W53 原先被算成下一年份的周。按算出的周一反查 ISO 年和周号，拒绝不存在的刊期；2020-W53 等真实第 53 周继续可用。
4. **统计状态回退。** 较早请求晚返回会覆盖新的星标数；旧数字 RAF 动画也会覆盖新动画。分别加入请求序号与每个元素的动画序号，过期结果停止写入。
5. **列表忙碌时丢失实时信号。** 原先先保存最新轮询信号再因 loading 返回，下一轮误以为已经处理。现在仅在允许处理时提交信号，忙碌结束后仍能发现变化。
6. **清理接收与完成反馈失真。** 原接口未确认锁就返回已开始；失败没有对应结果，前端还会把旧完成或等待耗尽当作成功。现先预留锁并返回 pruneId，所有成功/失败结果带相同 id；采集、压缩、重复清理和关闭遵守锁及排空约束。页面只确认对应任务，失败和超时显示实情，忙碌跳过不显示绿色成功。
7. **桌面 IPC 信任校验不统一。** 真实 Electron 夹具中的额外 BrowserWindow 能调用偏好、存储、归档、壁纸等入口。统一注册包装器，异步请求拒绝、同步请求返回 null，处理函数无副作用；主窗口功能通过。该夹具主动创建了具备 Node 的测试窗口，用于证明边界，不把它表述为外部站点已能创建窗口的攻击链。
8. **公开地址误拦与特殊 IPv6 漏判。** 原规则把整个 192.0/16、198.51/16、203.0/16 排除，也未规范化 IPv6 的前导零。按 IANA 的实际前缀判定，保留 192.0.0.9/.10 全球例外，拒绝 2001:db8/32、2001:2::/48、3fff::/20 文档及基准地址；相邻地址用例证明没有扩大误拦。
9. **混合审核/参数报错重复发送。** 原 400 判断在含参数词时跳过审核分类。审核标志优先，混合报错只请求一次；原网络、429、5xx 与参数兼容重试继续保留。
10. **信源地址冲突错误不可处理。** 实际 HTTP 重复创建原返回 500。创建/编辑在写入前检查唯一地址，返回 409 及操作提示，不改写任一已有信源；移出后的同地址恢复仍使用原 id。
11. **开发依赖分类漏掉桌面运行时审计。** 原生产依赖审计为零，但完整 npm audit 报告 14 项受影响依赖（5 高危、9 中危），其中 Electron 42.7.0 实际进入安装包。官方公告要求升级 preload 缓存修复版，42 系列修复下限为 42.10.0。本版采用当前同主版本稳定版 42.11.11，更新构建依赖补丁；global-agent 4.1.3 保留下载器所用 bootstrap API，去掉无修复版的 sprintf-js 依赖链，不降级 electron-builder。新增真实本地代理回归及 CI/Release 完整树审计，防止重复遗漏；未变更生产 JavaScript 依赖的版本。
12. **发布组件清单遗漏 Electron。** 原 CycloneDX CLI 的 omit dev 同样排除了实际交付的运行时。保留生产 JS 依赖图，补入已安装且与锁文件一致的 Electron、根依赖边及 MIT 声明；拒绝错版、再次执行完整 1.6 schema 校验后才写入附件。真实 CLI 生成、幂等及错版拒绝纳入单元矩阵。Chromium 等内嵌组件的原始许可证仍随安装器交付，不把 npm 下载器作为运行组件列入。
