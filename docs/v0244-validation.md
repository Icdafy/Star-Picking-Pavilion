# v0.2.44 验证记录

本版优化采集与分析的等待链路，并补齐任务全流程进度。以下记录区分本地验证、可复跑的隔离性能实验与最终发布结果。

## 实现

- 每个信源在开始请求时即报告活动；海外探测、采集后发布时间补查都有明确的开始、逐条进度和结束，信源完成数不冒充任务完成数。
- 翻译、正文、配图、图片理解、两路独立评分、内容理解、归组、合并、综述、导语及历史事件时间修补通过可选观察回调报告状态；观察者失败不会打断模型调用或写库。
- 任务上下文仅传递必要状态。模型开始、限流、网络重试及等待均可见，不将请求头、API Key、新闻正文或提示词送入进度数据；保持原有请求超时和重试上限。
- 后端任务期间每秒发送状态，前端展示总用时、当前步骤用时、在途任务用时、当前步骤真实计数与待分析条数。完成、失败及预算暂缓保留摘要，设置页可回看。未知总量不构造整体百分比或预计剩余时间。
- 翻译以单路与国内分析交叠；每篇最多两路配图下载后按原序组装；尾部综述最多两路并发，保持每轮上限、证据哈希复核、回执与预算。评分仍是三个文章 worker，每篇两次独立评分与一次内容理解。
- 渐进批次保留即时归组和热度，全窗口门槛重判由每批一次改为整轮尾部一次。尾部历史修补如改变事件时间，仍再次刷新必要热度与分数。

## 边界

性能实验仅使用固定延迟的本机模拟输入，不使用用户密钥或付费模型调用，不能等同于201个信源的实网速度承诺。模型等待仍取决于提供商、网络、内容数量和图片数量。步骤可并行，步骤耗时不能相加为总耗时。
