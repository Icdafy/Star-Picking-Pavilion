# v0.2.30 验证记录

日期：2026-10-07（北京时间）。本版调整更新图标的动效、悬停与实时进度显示。

## 实现

原控件采用上传 SVG 的静态第一帧，外圈和百分比仅在悬停或键盘聚焦时揭示。本版保持原 SVG 几何与按钮节点，中间箭头通过 CSS 持续旋转；悬停或键盘聚焦只改变箭头与数字层的可见性，不替换动画、按钮或外圈节点。

已知下载进度的外圈始终可见，使用现有控制器与百分比共用的限幅、取整数据，更新时作 180ms 线性过渡，不引入独立模拟进度。未知进度保留中间动效，外圈采用等待旋转且不显示百分比。下载完成外圈填满；失败重试、重启安装、无待更新时隐藏的行为保留。

系统减少动态效果与窗口失焦时停止装饰动画，实时进度仍可显示。无新增依赖，不修改安装与发布工作流。
