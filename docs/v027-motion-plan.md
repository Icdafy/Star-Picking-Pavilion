## 六条交互的实现口径

1. 导航：点击立即更新选中态与 roving tabindex；指示块跟随选中标签；目标面板入场 260ms，同一目标只保留最新动画，离开的面板清理运动。
2. 信息流：输入立即显示检索状态；网络请求显示 aria-busy，重置沿用原骨架与最短驻留，竞态只接受最新查询。分页复用旧节点；实时更新不抢阅读焦点和位置。仅可见的新行入场，最多八行，默认错峰 25ms，总延迟 175ms。第二轮尝试保留旧内容并立即调和，性能门槛未通过，第三轮撤回此项。
3. 星标/复制/Toast：操作立即显示忙碌状态；成功以后更新数据和反馈；Toast 文本立即替换，使用运动引擎重播，取消强制布局的重放方式。
4. 面板：统一进出时长与距离，保留命令面板键盘/ARIA；词库 Esc 归焦，选词把焦点交给检索框；确认框取消不继承上次 OK 的结果。
5. 主题：主题意图、DOM 与持久化入口同步更新，取消异步整屏揭开覆盖最新意图的路径。颜色过渡保留现有 260ms 契约，按钮微反馈 140ms；减少动画/隐藏时清除临时状态。
6. 外观：维持 full/lite/static 档位和背景开关；运行中减少动画、隐藏及离开页面时清理正在运行的有限动画，恢复后允许新交互。

取舍理由：整屏圆形揭开把主题写入放到了异步回调里，既影响连点正确性，也让阅读画面被大面积遮罩覆盖。本版选择同步主题与短颜色过渡，保留双主题材质和背景。真实观感由前后回放提供，不自封质量等级。
