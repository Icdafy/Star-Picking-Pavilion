# v0.2.38 验证记录 · 流体设计与极光引擎

## 范围

v0.2.38 为整个摘星阁引入“流体设计”——凝光视效、流体动效与柔性反馈三部分组成的全感官设计语言，运行时统一由新的极光引擎（`renderer/aurora-engine.js`）调度，样式集中在 `renderer/fluid.css`。设计参考了 ColorOS 17 公开介绍的“流体设计”（光作为界面意图的指引：进度条追光、滑动时光随指弥散、切换时的涟漪；按压收缩、拖动拉伸、松手回弹）以及极光引擎“系统层统一调度与渲染”的思路。摘星阁是 Electron 应用，无法接入手机系统的渲染管线，因此采用浏览器内最接近的等价架构：

| 系统能力 | 摘星阁中的对应实现 |
| --- | --- |
| 融合渲染、统一调度 | 单一按需 RAF 帧时钟承载柔性物理、水滴连桥与果冻滑动；涟漪、追光与入场交给 WAAPI 合成层；无任务即停 |
| 按负载降级 | 自动档按 `fx-tier`、电量（≤ 20% 且未充电）与实测连续掉帧切到轻盈档，20 秒后试探恢复 |
| 只动合成层 | 运动只写 `translate` / `scale` 独立变换与 `opacity`，不改布局属性，不新增 `@keyframes` |

本项目不宣称 OPPO 公布的内存与渲染负载数字；本版实测数据见下文。

## 实现要点

- **凝光视效**：云母材质更通透（仍随磨砂度变化）；`.glass::after` 为 1px 渐变轮廓光，卡片描边常亮；动态背景关闭时 body 显示静态的四点极光底色（无动画、无逐帧绘制）。非控件处按下生成光核 + 三圈涟漪（轻盈档一圈，同时最多 3 个，1.6 秒内移除）；按钮光波改为光核。系统“降低透明度”或强制配色时改回实底。
- **下拉压暗**：`.fluid-scrim` 位于 `#appViewport` 内并随滚动定位；`:has(select:open)`、导出菜单、核心词库打开时先淡入，选项面板延迟 90ms 浮现。原生 `<select>` 在 `@supports (appearance: base-select)`（Electron 42 / Chromium 148 支持）下改为玻璃选项面板，选中高亮、箭头翻转；关闭流体设计时回到原生下拉。浮出面板改用更实的底色，保证正文可读。
- **彗星追光**：`CSS.registerProperty` 注册 `--fluid-comet` / `--fluid-glint`，滑杆轨道上的光沿已填充部分移动；悬停与聚焦时循环，改值单次，拖动时锁定在滑块处并显示弥散光晕。
- **悬浮控件**：顶栏、筛选栏、指挥栏、设置目录、日志 / 一级市场 / 常用网址 / 信源 / 信息流 / 更新日志工具条统一 1.5rem 圆角与浮起阴影；栏内控件统一 2.375rem 高度与胶囊圆角。
- **柔性反馈**：按钮、搜索框、下拉、summary 与设置目录按下时按尺寸收缩（最多 8.5%），松手以低阻尼弹簧回弹（实测搜索框按下 0.922 → 松手 90ms 过冲至 1.026 → 静止后清除内联样式）。工具栏按钮拖动超过 8px 后橡皮筋跟随、沿速度方向拉伸；距离同组邻居 34px 内时邻居被吸引，并在所在面板 z-index:-1 的 SVG 层绘制 metaball 连桥；重叠时邻居淡出让字。松手后吞掉一次 click，Esc、pointercancel 与失焦取消。
- **流体滑动**：只由真实输入（滚轮、滚动键、拖动滚动条）触发，程序滚动不触发。可见块按与手势位置的距离滞后，速度越快增益与刚度越大；到达顶部或底部继续滚轮时约 50px 内橡皮筋拉开再弹回。视图切换按侧栏方向入场并带回弹。
- **档位偏好**：新增 UI 偏好字段 `fluidMode`（auto / full / lite / off，默认 auto），renderer 与主进程共用白名单校验；“设置 → 氛围与动效 → 流体设计”显示当前档位与原因（如“自动适配：当前为完整档 · 144Hz 高刷”）。

## 以使用者身份的体验检查

脚本 `work/v0238/experience.cjs`（未入库）复制本机真实数据（不含密钥）到临时目录，前台聚焦真实窗口，在浅色、深色、轻盈档、关闭档与 860px 窄窗口下依次：点卡片、按住搜索框、拖动领域胶囊直至与邻居重叠、拖动顶栏图标、快速滚轮、在顶部继续上拉、悬停并拖动滑杆、打开两个下拉、打开词库、切换全部视图，并在动画中途截帧。

- 完整档：涟漪 1 个并在 1.6 秒内清理；拖拽中连桥路径 1 条，松手后物理体、连桥层全部清除，领域筛选与命令面板均未被误触发；快速滚动时 5 个可见块最大滞后约 20px，1.2 秒内全部复位；顶部继续上拉最大约 45px。
- 帧耗时（144Hz 显示器，40 次快速滚动 + 果冻回弹期间 210 帧）：p50 6.90 ms、p95 7.70 ms，超过 20 ms 的帧 2 个；JS 堆约 6 MB。
- 轻盈档：按压回弹与单圈涟漪保留，拖拽无连桥，果冻滑动关闭。关闭档：无涟漪、无按压缩放、无压暗，下拉回到原生样式。
- 全程无页面错误或控制台错误。

## 限制

- 下拉玻璃面板依赖 Chromium 的 `appearance: base-select`；不支持时自动保留原生下拉，仍有压暗。
- 果冻滑动只在完整档启用；触控板惯性滚动按滚轮事件处理。
- 动态背景关闭时的极光底色是静态渐变，不随指针或时间变化，以免增加常驻绘制。
